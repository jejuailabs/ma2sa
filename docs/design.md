## 레이아웃

### PC (≥1024px)
- 최대 너비: `1200px`, 중앙 정렬
- 상단 GNB: 로고 좌측, 메뉴(마을 소식 / 이벤트 / 마을 특산품 / 소개 / 이용안내) 중앙, 로그인/프로필 우측
- 히어로 섹션: 풍경 배경 이미지 + 타이틀 오버레이 + CTA 버튼 2개
- 카테고리 카드: 3열 그리드 (마을 소식 / 이벤트 / 마을 특산품)
- 피드: 4열 카드 그리드

### 모바일 (<768px)
- 상단: 햄버거 메뉴 (좌) / "Home" 타이틀 (중앙) / 알림 아이콘 (우)
- 검색바: 전체 너비
- 카테고리 탭: 가로 스크롤 (마을 소식 / 이벤트 / 마을 특산품)
- 피드: 1열 카드, 좌우 스와이프 이미지 갤러리
- 하단 탭바: 4개 아이콘 (홈 / 문서함 / 검색 / 마이)

### 대시보드 (로그인 후)
- PC: 좌측 사이드바 (메뉴) + 우측 메인 콘텐츠
- 모바일: 사이드바 → 햄버거 메뉴로 전환
- 상단 인사 영역: "김사무장님, 오늘도 행복한 금성리 마을입니다" + 날씨
- 요약 카드: 6개 아이콘 카드 (마을 소식 / 이벤트 / 마을회의 / 마을대장 / 할일 / 자금현황)
- 중앙: 마을 소식 리스트 + 오늘 할 일
- 우측/하단: AI 기능 버튼 + 최근 업로드 사진

## 컴포넌트 목록

### 공통
- `Header` — GNB (PC: 풀 메뉴, 모바일: 햄버거)
- `BottomTabBar` — 모바일 하단 탭바 (홈/문서함/검색/마이)
- `ThemeToggle` — 다크/라이트 모드 토글 스위치
- `SearchBar` — 검색 입력 필드
- `CategoryTabs` — 마을 소식 / 이벤트 / 마을 특산품 탭
- `Avatar` — 프로필 이미지 (원형)
- `Badge` — 최신 소식, 카운트 배지

### 피드
- `FeedCard` — 소식 카드 (프로필 + 타이틀 + 이미지 갤러리 + 좋아요/댓글/공유)
- `ImageGallery` — 이미지 여러 장 표시 (메인 1장 + 우측 2장, 추가 이미지 카운트 오버레이)
- `FeedActions` — 좋아요(하트) + 댓글 + 공유 액션 바

### 대시보드
- `DashboardGreeting` — 인사말 + 날씨 위젯
- `StatCard` — 요약 카드 (아이콘 + 라벨 + 수치)
- `TodoList` — 오늘 할 일 체크리스트
- `AIFeatureButton` — AI 기능 바로가기 버튼
- `PhotoGrid` — 최근 업로드 사진 그리드
- `SidebarMenu` — 좌측 사이드바 메뉴 (대시보드/내 마을/마을 소식/마을 특산품/AI 기능/문서함/자금 관리/장부 열람)

### 인증
- `GoogleLoginButton` — Google 로그인 버튼
- `VillageSelector` — 마을 검색/선택 입력 필드 (autocomplete)

## 이미지 갤러리 레이아웃 (피드 카드)

모바일 참조 이미지 기준:

```
┌──────────────┬────────┐
│              │  img2  │
│    img1      ├────────┤
│   (메인)     │  img3  │
│              │ [📷 15]│
└──────────────┴────────┘
```

- 메인 이미지: 좌측 약 60% 너비, 전체 높이
- 우측: 2개 이미지 수직 배치, 각 50% 높이
- 추가 이미지 있을 경우 우측 하단에 카운트 오버레이 (`📷 15`)

## 간격 및 둥글기

- 카드 패딩: `16px` (모바일) / `24px` (PC)
- 카드 간 간격: `16px`
- 카드 border-radius: `12px`
- 버튼 border-radius: `8px`
- 아바타 border-radius: `50%` (원형)
- 섹션 간 여백: `32px` (모바일) / `48px` (PC)

## 아이콘

Lucide React 또는 Heroicons 사용 권장. 대시보드 요약 카드의 아이콘은 커스텀 SVG 또는 이모지로 대체 가능.

## 애니메이션

- 피드 카드 등장: fade-in + slide-up (200ms ease-out)
- 탭 전환: 하단 인디케이터 슬라이드 (150ms)
- 다크모드 전환: 전체 CSS transition (300ms)
- 버튼 호버: scale(1.02) + 그림자 증가
