# AI 기능 상세 스펙

## 개요

이장/사무장 권한 사용자에게 제공되는 6가지 AI 업무 도구.
대시보드의 **AI 기능** 섹션에서 버튼으로 접근한다.

## 공통 아키텍처

```
[사용자 UI]
    │
    ▼ (파일 업로드 or 텍스트 입력)
[Firebase Storage/Firestore]
    │
    ▼
[Firebase Function]
    │
    ├── 전처리 (OCR, STT 등)
    ├── Claude API 호출 (분석, 요약, 변환)
    └── 후처리 (파일 생성, DB 저장)
    │
    ▼
[결과 반환 → UI 표시 + 다운로드]
```

## 1. 공고문 분석

### 흐름
1. 사용자가 공고문 이미지/PDF 업로드
2. OCR로 텍스트 추출
3. Claude API에 텍스트 전달 → 분석 요청
4. 결과 표시: 핵심 요약, 신청 자격, 마감일, 지원금액, 필요 서류

### 프롬프트 구조 (Claude API)
```
시스템: 당신은 마을 이장/사무장을 위한 공고문 분석 도우미입니다.
사용자: 아래 공고문 내용을 분석해주세요.
- 사업명
- 사업 목적 요약
- 신청 자격/대상
- 지원 내용 (금액, 혜택)
- 신청 기한
- 필요 서류 목록
- 이장/사무장이 해야 할 액션 아이템

[공고문 텍스트]
```

### UI
- 업로드 영역 (드래그 앤 드롭 / 파일 선택)
- 분석 중 로딩 표시
- 결과: 카드 형태로 항목별 정리
- "문서함에 저장" 버튼

---

## 2. 영수증 → 엑셀 변환

### 흐름
1. 영수증 이미지(들) 업로드
2. OCR로 텍스트/표 추출
3. Claude API로 구조화 (날짜, 품목, 수량, 단가, 합계)
4. 엑셀 파일 생성 + 대시보드 차트 데이터 저장

### 데이터 구조
```typescript
interface ReceiptItem {
  date: string;
  vendor: string;       // 판매처
  item: string;         // 품목
  quantity: number;
  unitPrice: number;
  total: number;
  category: string;     // AI가 자동 분류 (식비, 사무용품, 행사비 등)
}
```

### UI
- 다중 이미지 업로드
- 변환 결과 테이블 미리보기
- "엑셀 다운로드" 버튼
- 대시보드 자금 현황에 자동 반영 옵션

---

## 3. 텍스트 → 양식 변환

### 흐름
1. 사용자가 텍스트 또는 초안을 입력 (혹은 파일 업로드)
2. 변환할 양식 템플릿 선택
3. Claude API로 양식에 맞게 내용 재구성
4. 변환된 문서 다운로드 (HWPX, DOCX)

### 지원 양식
- 마을 사업계획서
- 보조금 신청서
- 결과보고서
- 회의록 (공식 양식)
- 마을 공지문

### 양식 템플릿 관리
- 기본 제공 양식 세트
- 사용자가 양식 추가 가능 (파일 업로드)
- 양식별 필드 매핑 정보 저장

### UI
- 좌측: 텍스트 입력 영역
- 우측: 양식 선택 + 변환 결과 미리보기
- "다운로드 후 편집" 버튼

---

## 4. 회의록 자동 정리

### 흐름
1. 녹음 파일 업로드 (MP3, WAV, M4A 등)
2. STT(Speech-to-Text)로 텍스트 변환
3. Claude API로 회의록 형태 정리

### Claude 정리 항목
- 회의 일시, 장소, 참석자
- 안건별 논의 내용 요약
- 결정 사항
- 향후 조치 사항 (담당자, 기한)
- 특이사항/기타

### 제약사항
- 최대 녹음 시간: 60분 (Firebase Storage 용량 고려)
- STT 정확도 한계 → 변환 결과 수동 교정 UI 제공
- 화자 분리는 MVP에서 미지원 (향후 추가)

### UI
- 녹음 파일 업로드 + 녹음 직접 기능(옵션)
- STT 변환 결과 편집 가능
- AI 정리 결과 미리보기
- "회의록 다운로드" + "문서함 저장" 버튼

---

## 5. 대신 읽어주기 (AI 나레이션)

### 흐름
1. 방송할 내용 텍스트 입력
2. 나레이션 스타일 선택 (공지/친근/유머)
3. Claude API로 텍스트 다듬기 (마을 방송 톤)
4. TTS API로 음성 생성
5. 음성 파일 재생/다운로드

### 나레이션 스타일
| 스타일 | 설명 | 예시 |
|--------|------|------|
| 공지 | 정중하고 명확한 톤 | "주민 여러분, 안녕하십니까..." |
| 친근 | 따뜻하고 친근한 톤 | "우리 마을 주민 여러분~" |
| 유머 | 재미있고 경쾌한 톤 | "여러분! 오늘 이 소식 안 들으면 손해!" |

### Claude 텍스트 변환 프롬프트
```
시스템: 당신은 마을 방송 원고 작성자입니다. 
주어진 내용을 마을 스피커로 방송하기 적합한 형태로 바꿔주세요.
스타일: {선택된 스타일}
- 자연스러운 구어체
- 적절한 호흡 위치 표시
- 핵심 정보는 반복
```

### UI
- 텍스트 입력 영역
- 스타일 선택 (3개 라디오)
- "텍스트 다듬기" → 변환 결과 확인
- "음성 생성" → 오디오 플레이어
- "다운로드" (MP3)

---

## 6. 마을 문서함

### 기능
- AI 기능으로 생성된 모든 문서를 통합 관리
- 카테고리별 분류: 공고문/영수증/양식문서/회의록/나레이션
- 검색 기능
- 파일 다운로드/삭제
- 사진 업로드 및 갤러리

### 데이터 모델
```typescript
interface Document {
  id: string;
  villageId: string;
  type: 'announcement' | 'receipt' | 'formatted' | 'minutes' | 'narration' | 'photo';
  title: string;
  description: string;
  fileURL: string;          // Firebase Storage 경로
  thumbnailURL: string;
  createdBy: string;
  createdAt: Timestamp;
  aiGenerated: boolean;     // AI로 생성된 문서 여부
  metadata: Record<string, any>;
}
```

### UI
- 카테고리 탭 필터
- 그리드/리스트 뷰 토글
- 각 문서 카드: 썸네일 + 제목 + 날짜 + 다운로드
- 사진 업로드: 드래그 앤 드롭 + 카메라 (모바일)

## AI 기능 허브 페이지 레이아웃

대시보드에서 "AI 기능 바로가기" 클릭 시:

```
┌─────────────────────────────────────────┐
│          AI 기능                         │
├──────────┬──────────┬──────────┐        │
│ 📋       │ 🧾       │ 📝       │        │
│ 공고문   │ 영수증   │ 텍스트→  │        │
│ 분석     │ →엑셀    │ 양식변환 │        │
├──────────┼──────────┼──────────┤        │
│ 🎙       │ 📢       │ 📁       │        │
│ 회의록   │ 대신     │ 문서함   │        │
│ 정리     │ 읽어주기 │          │        │
└──────────┴──────────┴──────────┘        │
└─────────────────────────────────────────┘
```

각 버튼 클릭 시 해당 기능 페이지로 이동하거나, 모달/슬라이드 패널로 표시.
