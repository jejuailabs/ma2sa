# 마을 생성 및 가입 흐름

## 개요

마을은 두 가지 경로로 시스템에 등록된다:
1. **최초 생성** — 이장/사무장이 처음 마을을 등록
2. **이후 가입** — 주민이 이미 생성된 마을에 가입

## 최초 생성 흐름 (이장/사무장)

```
[Google 로그인 완료]
        │
        ▼
[마을 지정 페이지 /village/setup]
        │
        ▼
[마을 이름 입력 필드]
  ├── 타이핑 시 실시간 검색 (autocomplete 펼침 목록)
  │   ├── Firestore 기존 마을 목록 검색
  │   └── 외부 API 매칭 (행정구역 데이터)
  │
  ├── [기존 마을 선택] → 가입 흐름으로 이동
  │
  └── [새 마을 만들기] 클릭
        │
        ▼
  [마을 기본 정보 수집]
  ├── 자동: 마을종합지원센터 크롤링
  │   ├── 마을 위치 (시·군·구·읍·면·리)
  │   ├── 마을 인구 정보
  │   ├── 마을 특산물
  │   └── 관련 사진/자료
  │
  ├── 수동 입력 (크롤링 실패 시 폴백)
  │   ├── 마을 주소
  │   ├── 마을 소개 (선택)
  │   └── 대표 이미지 업로드 (선택)
  │
  └── [마을 생성 완료]
        │
        ▼
  [마을 대시보드 자동 생성]
  ├── 기본 정보 카드 세팅
  ├── 빈 피드 + 첫 글 작성 유도
  └── 초대 링크 생성 안내
```

## 마을 이름 입력 필드 (Autocomplete)

### 동작 방식

1. 사용자가 마을 이름을 입력하기 시작
2. 2글자 이상 입력 시 실시간 검색 트리거
3. 펼침 목록(dropdown)에 검색 결과 표시:
   - **이미 등록된 마을** (Firestore) → "가입하기" 라벨
   - **행정구역 매칭** (외부 API) → "새로 만들기" 라벨
4. 항목 선택 시 해당 흐름으로 분기

### 검색 소스

| 순서 | 소스 | 설명 |
|------|------|------|
| 1 | Firestore `villages` | 이미 생성된 마을 |
| 2 | 행정안전부 행정구역 API | 법정리·행정리 코드 매칭 |
| 3 | 마을종합지원센터 | 마을 상세 정보 크롤링 |

### UI

```
┌─────────────────────────────────────┐
│ 🔍 마을 이름을 입력하세요           │
├─────────────────────────────────────┤
│ 📍 금성리 마을 (제주시 한림읍)  가입│
│ 📍 금산리 마을 (제주시 조천읍)  가입│
│ ─────────────────────────────────── │
│ ＋ "금성" 으로 새 마을 만들기       │
└─────────────────────────────────────┘
```

## 마을 데이터 모델

```typescript
interface Village {
  id: string;                      // Firestore 문서 ID
  name: string;                    // 마을 이름
  address: string;                 // 주소 (시·군·구·읍·면·리)
  regionCode: string;              // 행정구역 코드
  description: string;             // 마을 소개
  photoURL: string;                // 대표 이미지
  population: number | null;       // 인구 수
  specialties: string[];           // 특산물
  createdBy: string;               // 최초 생성자 UID
  createdAt: Timestamp;
  memberCount: number;             // 가입 멤버 수
  settings: VillageSettings;
}

interface VillageSettings {
  isPublic: boolean;               // 피드 공개 여부
  requireApproval: boolean;        // 가입 승인 필요 여부
  inviteOnly: boolean;             // 초대 전용 여부
}
```

## 이후 가입 흐름 (주민)

```
[Google 로그인 완료]
        │
        ▼
[마을 지정 페이지]
        │
        ▼
[마을 이름 검색] → 기존 마을 선택
        │
        ├── 자동 승인 마을 → 즉시 가입 완료
        └── 승인 필요 마을 → 이장/사무장에게 가입 요청 전송
                              │
                              ▼
                        [승인 대기 상태]
                              │
                              ▼
                        [승인 완료] → 마을 대시보드 접근
```

## 초대 링크

이장/사무장이 대시보드에서 생성:

```typescript
interface Invite {
  code: string;          // 8자리 랜덤 코드
  villageId: string;
  createdBy: string;     // 생성자 UID
  createdAt: Timestamp;
  expiresAt: Timestamp;  // 기본 7일
  usedBy: string[];      // 사용한 사용자 UID 목록
  maxUses: number;       // 최대 사용 횟수 (0 = 무제한)
}
```

## 마을종합지원센터 크롤링

마을 생성 시 자동으로 수행하되, 크롤링 실패 시 수동 입력으로 폴백:

- 크롤링 대상: 마을 기본 현황, 특산물, 주요 사업, 사진
- 결과는 Firestore에 캐싱 (24시간 TTL)
- 크롤링 상태를 사용자에게 표시 (로딩 → 완료/실패)
