# 대시보드 화면 스펙

## 개요

이장/사무장이 로그인 후 업무모드에서 보는 마을 관리 화면.
참조 이미지: `이장_및_사무장_업무모드_화면.png` (시안 3: 내추럴 그린 힐링 대시보드)

## 접근 경로

```
Google 로그인 → 마을 지정 완료 → /village/{villageId}
또는 프로필 → 마이페이지 → 업무모드 전환
```

## 섹션별 상세

### 1. 인사 영역

```
김사무장님,
오늘도 행복한 금성리 마을입니다         24°C ☀
```

- 사용자 displayName + 역할 호칭 ("사무장님", "이장님")
- 마을 이름
- 날씨: 마을 위치 기반 (공개 날씨 API)
- 배경: 내추럴 그린 일러스트 (산/나무/감귤)

### 2. 요약 카드 (6개)

| 카드 | 아이콘 | 데이터 소스 |
|------|--------|-------------|
| 마을 소식 | 📰 | `posts` 컬렉션 count |
| 이벤트 | ⭐ | `events` 컬렉션 count |
| 마을회의 | 👥 | `meetings` 컬렉션 count |
| 마을대장 | 📋 | `members` 컬렉션 count |
| 할일 | ✅ | `todos` 미완료 count |
| 자금현황 | 💰 | `finances` 잔액 합계 |

각 카드 클릭 시 해당 상세 페이지로 이동.

### 3. 마을 소식 (최신 3건)

- Firestore `posts` 컬렉션에서 최신 3건 표시
- 제목 + 날짜 + 요약 1줄
- "더 보기" → 피드 페이지로 이동

### 4. 오늘 할 일

- 체크리스트 형태
- 체크 시 Firestore 업데이트 (실시간)
- "+ 할 일 추가" 인라인 입력
- 완료된 항목은 취소선 + 회색 처리
- "할 일 없음" → "할 일을 추가해보세요" 빈 상태

### 5. AI 기능 바로가기

- "AI 기능 바로가기 →" 버튼 카드
- 클릭 시 `/village/{id}/ai` 로 이동
- 또는 6개 아이콘 버튼을 직접 표시

### 6. 최근 업로드 사진

- Firebase Storage에서 최근 8장 표시
- 그리드 (4x2 또는 가로 스크롤)
- 클릭 시 확대 뷰
