# 마을 소식 피드 스펙

## 개요

메인 화면의 핵심 콘텐츠. SNS 피드처럼 마을 소식을 카드 형태로 표시한다.
비로그인 사용자도 공개 피드를 열람할 수 있다.

참조 이미지:
- `메인화면_마을_소식_피드화면_pc_.png` — PC 레이아웃
- `메인화면_마을_소식_피드화면_모바일_.png` — 모바일 레이아웃

## 카테고리 탭

| 탭 | 아이콘 | 데이터 소스 |
|----|--------|-------------|
| 마을 소식 | 🏘 | `posts` where type == 'news' |
| 이벤트 | 📅 | `events` 컬렉션 |
| 마을 특산품 | 🧺 | `products` 컬렉션 |

탭 전환 시 하단 인디케이터 애니메이션 + 콘텐츠 fade 전환.

## 피드 카드 (FeedCard) 컴포넌트

### 데이터 모델

```typescript
interface Post {
  id: string;
  villageId: string;
  villageName: string;
  authorId: string;
  authorName: string;        // "김성리 마을회"
  authorPhotoURL: string;
  title: string;              // "가족과 함께하는 연날리기 축제 🌈"
  content: string;            // "푸른 하늘 아래, 마을 주민들과..."
  images: string[];           // Firebase Storage URL 배열
  likeCount: number;          // 1.9k
  commentCount: number;       // 432
  shareCount: number;
  createdAt: Timestamp;
  updatedAt: Timestamp;
  isPublic: boolean;
  tags: string[];
}
```

### 이미지 갤러리 규칙

| 이미지 수 | 레이아웃 |
|-----------|----------|
| 0 | 이미지 영역 없음 |
| 1 | 전체 너비 1장 |
| 2 | 좌우 50:50 2열 |
| 3+ | 좌측 메인(60%) + 우측 2장(40%), 3장 초과 시 우측 하단에 카운트 오버레이 |

### 액션 바

```
♡ 1.9k     💬 432                    🔗 공유
```

- 좋아요: 토글 (Firestore subcollection `likes`)
- 댓글: 클릭 시 댓글 목록 펼침 또는 댓글 페이지 이동
- 공유: Web Share API (모바일) 또는 링크 복사 (PC)

## 무한 스크롤

- Firestore 커서 기반 페이지네이션 (`startAfter`)
- 한 번에 10개 로드
- Intersection Observer로 하단 도달 감지
- 로딩 스켈레톤 표시

## 글 작성

로그인 사용자만 가능. 피드 상단에 "새 소식 작성" 버튼 또는 FAB(모바일).

### 작성 폼
- 제목 입력
- 본문 입력 (마크다운 미지원, 플레인 텍스트)
- 이미지 첨부 (최대 15장)
- 공개/비공개 토글
- [게시] 버튼

## 검색

상단 검색바에서 마을 소식 전문 검색:
- Firestore 텍스트 검색 (제목, 본문)
- 향후: Algolia 또는 Typesense 연동으로 고도화
