# 공개 체험관

진입 주소는 `/experience`이며, 메인화면의 무료 체험 버튼과 행사 QR이 같은 주소로 연결된다. 로그인 없이 PC와 휴대폰에서 이용한다. `/experience`는 기존 인증 공급자 안에서 로그인 없이 이용할 수 있다. 실제 마을 관리자 화면과 기존 인증은 유지한다.

## 화면

- PC: 244px 좌측 마을 메뉴, 넓은 본문, AI 기능 3열 카드.
- 태블릿: 2열 카드, 메뉴 패널, 하단 탭.
- 휴대폰: 대표 사업계획서 카드, 2열 기능 카드, 4개 하단 탭, 네이티브 dialog 메뉴.
- 사업계획서: 기본정보 → 질문 8개 → 전체 답변 검토 → AI 정리 → 직접 수정·복사·파일 받기.
- 질문 화면은 하단 이전/다음 버튼을 고정하고 VisualViewport로 키보드 가림을 보정한다. 입력 글씨 16px 이상, 주요 버튼 44~54px 이상, 노치/홈 인디케이터 safe-area, 확대 허용, reduced-motion을 지원한다.
- 마을 데모 메뉴는 모두 예시 화면으로 연결되며 실제 주민 정보를 조회하지 않는다.

## AI 체험 활성화

UI 열람은 설정 없이 가능하다. 실제 AI 호출은 아래 서버 환경 변수를 설정할 때만 활성화된다. 미설정 시 API는 503과 안내문을 반환하며, 비용이 발생하는 AI 요청을 전송하지 않는다.

```
EXPERIENCE_ENABLED=1
EXPERIENCE_SESSION_SECRET=<32자 이상 무작위 비밀키>
UPSTASH_REDIS_REST_URL=<지속적인 제한 기록용 Redis REST 주소>
UPSTASH_REDIS_REST_TOKEN=<Redis REST 토큰>
EXPERIENCE_DAILY_LIMIT=300
EXPERIENCE_ENDS_AT=<선택: 체험 종료 시각, 시간대가 포함된 ISO 형식>
ANTHROPIC_API_KEY=<기존 서버 AI 키, CLAUDE_API_KEY도 지원>
OPENAI_API_KEY=<회의록 받아쓰기·음성 합성에 필요한 서버 키>
```

Redis REST 구현 근거: https://upstash.com/docs/redis/features/restapi

세션은 6시간 유효한 HttpOnly·SameSite=Strict 서명 쿠키다. HTTPS에서 Secure를 추가한다. 쿠키를 바꾸거나 서버 인스턴스가 변경돼도 Redis에서 기능별 1회, 계획서 2회를 검사한다. 원자적 Lua 스크립트로 동시 요청과 하루 전체 호출 상한을 제한한다. 실패한 처리의 기능별 횟수는 복구하지만 전체 호출 상한은 보수적으로 유지한다. 세션 발급은 같은 IP에서 하루 120회, 전체 하루 600회까지이며 행사장 공용 와이파이를 고려한다. 브라우저 초기화로 새 세션을 만들 수 있으므로 사람당 정확히 1회 보장을 뜻하지 않는다.

`EXPERIENCE_ENABLED`를 0으로 설정하면 AI 처리만 종료하고 페이지와 기기의 결과 확인·파일 생성은 계속 사용할 수 있다. 공개 체험 API는 `/api/experience/*`에서만 동작한다. 기존 `/api/ai/*`와 인증 흐름은 변경하지 않는다.

## 데이터·음성·파일

사업계획서 답변과 결과는 이 기기의 localStorage에 마지막 편집 후 24시간 동안 보관하며, 다시 열 때 만료 여부를 검사한다. 답변 지우기 버튼으로 제거한다. 서버 공용 문서함에는 저장하지 않는다. 대표자·연락처·주소는 AI로 전달하지 않고 출력 파일에만 포함한다. 공유는 기기의 공유 메뉴 또는 복사로 처리하며 서버 공개 결과 링크를 만들지 않는다.

음성 입력은 `SpeechRecognition`/`webkitSpeechRecognition` 기능을 감지하고 한국어를 요청한다. 지원 여부와 실제 인식 성능은 브라우저·기기에 따라 다르다. 60초 자동 중지, 권한 오류, 무음, 인식 중 수정, 페이지 이동 시 중지를 처리한다. 미지원 시 직접 입력/키보드 받아쓰기를 안내한다. 전용 음성 녹음 파일을 앱 서버에 저장하지 않는다. 브라우저가 외부 인식 서비스를 이용할 수 있다.

공개 파일 체험은 전체 4MB, 영수증 3장으로 제한한다. 결과 CSV에서 수식으로 해석될 수 있는 셀을 이스케이프한다.

마을공동체 HWPX는 제공된 가평군 공간조성 원본 양식의 표·스타일·헤더를 유지하여 생성한다. 과거 사업비 예시를 사용자 실적으로 넣지 않는다. 누락 사항·서명·증빙은 사람이 작성한다. 행복마을관리소는 공식 양식 미제공으로 텍스트 초안만 제공한다. ZIP/XML 유효성과 값 매핑은 자동 검증할 수 있으나 최종 페이지 배치는 실제 한글 프로그램으로 확인해야 한다.

## 배포 전 현장 확인

개발 브라우저의 여러 화면 크기에서 검증한 결과와 실제 기기 확인을 구분한다. Android Chrome, iPhone Safari, 카카오톡 내부 브라우저에서 마이크 권한, 키보드, 다시 접속, 파일 다운로드, 공유 메뉴를 확인한다. 원본 한글 양식에 긴 답변을 넣어 페이지 넘침을 확인한다. AI/Redis 서버 설정과 실제 사용량 제한을 확인한 후 배포된 `/experience` 주소로 QR을 만든다.
